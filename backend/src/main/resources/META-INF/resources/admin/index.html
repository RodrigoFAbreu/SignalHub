Users

A user has devices, producers and subscriptions, and receives only the events of the producers they are subscribed to. Basic users manage no devices; mods manage their own; admins manage everyone's that are not admins' and invite users. Making someone an admin is done only here.

    Invite a user

    Inviting creates the user. Then use Connect a device on their card to make them a pairing code; the device that uses it belongs to them.

    Events

      Send a test event

      Published as the producer you choose, so it is stored and pushed exactly as that producer's own event would be: each device's push preferences apply to it. Open it afterwards to delete it.

      Delete events

      Every event of a producer, every event received before a day, or both. You are told how many first. Deleted events are gone for good; producers and devices stay.

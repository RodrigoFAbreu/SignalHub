6Signing in to the web page: a QR code the app scans, or a code typed on a phone

There are no passwords: a browser becomes one of your devices by being approved from a device you already have, and every role can do it, a Basic user included. 6a is the sign-in on a screen wide enough for a camera to see (with a code as the alternative); 6d is the sign-in on a phone's own browser (a short code typed in the app, plus an Open the app button). After approval the browser shows up in Devices as a browser and can be revoked like any device. A sign-in lasts a fixed 30 days. Below: the waiting state, the code expiring, the app's scanner and confirm sheet, success, the phone-width sign-in, the problem states, and the signed-out states that keep the address to return to. This page signs in as Rodrigo (Admin) throughout. Dashed notes marked R66 decides are left to the web increment (R66) and are not specified here.

In order: the phone's person chose Cancel; wrong or run-out codes were tried too often (the button counts down and then turns into Show a new code); the server can't be reached (the page keeps trying on its own); a few refreshes with nobody approving; and a second tab of a browser that is already signed in. Each is one heading, one sentence and at most one button, and the buttons are 48 px tall. A new sign-in is not blocked by a full or revoked device list: a revoked browser simply signs in again as a new browser.

R66 decides: the try limit, the wait before trying again, and how the page notices a Cancel.

Left to right. (1) The 30 days end while a page is open: a banner (surface container high, like the app's banners), with the page's text kept so nothing is lost mid-read, and Sign in again. (2) That button, or a reload, shows the sign-in page at the same address; after approval the page opens that address, not the inbox. (3) A browser that was revoked: on its next request the page shows only a blank surface and "Checking…", never the old content. (4) Then "You're signed out", the same page as (2) apart from the heading and one sentence: both say nothing about why, so a revoked browser learns no more than an expired one (the server answers both the same way). (5) Signing out in another tab of this browser: the same banner pattern. Every banner button is 48 px tall.

R66 decides: how the page notices the other tab's sign-out.

Every role can sign in a browser, a sign-in lasts a fixed 30 days and revoking a browser signs it out. "Sign in a browser" is a Settings row beside Devices for every role.

4Connect a device and the pairing code

Companion to Admin - Devices.dc.html. Connect a device is one dialog (name, user) that leads, in the same place, to the pairing code: the QR, the link to copy, a countdown, and the two ways it ends (expired, or used by a named device). 760 px stages stand for the dialog over the 1440 frame. Dialog actions are text buttons, 48 px high: the confirming action in primary, a destructive one in the error colour. Every dialog is a modal with a name (its title), focus inside and Escape to close.

5Rename, revoke and delete, and the phone's sheets

These replaced the browser's prompt and confirm. Each says what happens in words, names the device, and keeps the dialog open with a message if the server refuses. Revoke and Delete are in the error colour because they cannot be undone; rename is not. Nobody is told of a change made on this page: no push goes out for a revoke, a rename or a delete.

It stops working at once, for good, and gets no more pushes. It is an admin device, so it also stops managing other devices. Its past events stay. Nobody is told.

CancelRevoke

Cancel has the focus, not the destructive button. For a signed-in browser the title is “Sign out “Ana - Home browser”?” and the text “The browser is signed out at once.

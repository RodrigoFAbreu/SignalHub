3Selecting, deleting, filtering

Companion to Admin - Events.dc.html (options and detail). Drawn in A. Selection and bulk delete, the header menu, a filter menu and a filtered list. Every control is 48 px high (pager, bulk bar buttons, row checkbox hit area, chip remove, snack bar action). Snack bars sit at the bottom left of the list area, above the pager, carry no Undo, and are announced with role=status.

Ticking a row (or its checkbox with the keyboard: Space) turns the filter chips into the bulk bar: count, “Select all 25 on this page”, Mark read, Delete; the header checkbox shows a dash for part of the page. The bar does not select beyond the page, so “Delete” never reaches events the operator cannot see; larger clean-ups use Delete events by rule. Mark read for a selection repeats the per-event call; the pane goes back to “Select an event” while several are ticked. Targets are 48 px: each bulk button, the clear (x) button, and the checkbox hit area (the box itself is 18 px). Names: “Clear the selection”, “Select Build 1842 failed on main” (the checkbox of a row names its event).

Producer, Category and Severity take several values (the API matches any of them): each chip opens a menu of checkboxes, 48 px rows, and fills with its values (“Severity: Critical, High”, or “Severity: 3” when they do not fit). User and Read state stay single choice: User offers the users by name (a revoked one marked), Read state offers Read and unread, Unread only, Read only. Push problems is a plain on/off chip. Closing the menu applies the choice (Esc closes it and keeps the choice).

Every control shows a 2 px primary ring: the table is one tab stop with arrow keys between rows (Enter opens the row, Space ticks it), the header buttons and the pane tabs are each a stop. Esc closes a dialog and the pane. Focus returns to the row after a dialog closes. Landmarks: the rail is a nav (the current item has aria-current), the list and pane are in main; the page title Events is the h1 and the pane's title is an h2. Icon buttons have names (Refresh, More, Clear the selection).

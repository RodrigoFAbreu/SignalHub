4Invite a user, then connect their first device

Companion to Admin - Users.dc.html. Inviting is two steps in one dialog: the name and role, then the pairing code for the user's first device, drawn like the one on Devices (G2). The roles are said the way the users' app and web page say them, as a choice of three with one sentence each, not a bare select. 760 px stages stand for the dialog over the 1440 frame. Dialog actions are text buttons, 48 px high: the confirming action in primary, a destructive one in the error colour.

5Role changes, subscriptions, rename and revoke

Everything that acted at once or through a browser confirm now asks in the page: a role change (three sentences, one for each direction, the strong ones in the error colour), unsubscribing (it acted without asking before), and revoking a user (with the counts it affects). Subscribing and renaming are plain forms. Confirmations of reversible changes (a role, a subscription) use a primary text button; revoking, which cannot be undone, uses the error colour as text.

UC1Make a user a Mod

Make Rui a Mod?

Rui will manage their own devices: rename, revoke, and connect new ones. Their devices and producers stay as they are.

CancelMake Mod

Mod to Basic reads “Make Rui a Basic user?” with “Rui will no longer connect, rename or revoke devices. The ones they have keep working.” and the button “Make Basic”.

UC2Make a user an Admin

Make Ana an Admin?

Ana will see every device, manage the devices of users who are not admins, and invite users. Their devices become admin devices.

admin_panel_settings
Only you can take it away again, on this page.
CancelMake Admin

Cancel has the focus. The error-colour text button is for the one change that gives power to someone else; it is not a filled red button.

UC3Take Admin away (the last admin)

Take Admin away from Rodrigo?

Rodrigo becomes a Mod. Their devices stop being admin devices at once and can no longer see or manage other people's.

info
Nobody will be an admin in the app. The admin token still works here.
CancelMake Mod

From Admin the segment offers Mod or Basic; this is the Mod sentence, and Basic adds “and lose the ability to manage their own devices”. The server has no last-admin guard, so the change is never refused. When it removes the last admin user, the dialog adds the sentence above and then goes ahead; the warning is shown only in that case. Revoking an admin user (UC6) makes them Basic as they are revoked and shows the same sentence when they are the last admin.

UC4Unsubscribe

Unsubscribe Ana from ci-pipeline?

Ana stops receiving its events in their app, and the events it already sent disappear from their inbox too. They come back if Ana subscribes again, while the producer is public or allows them.

CancelUnsubscribe

Before this, the old page unsubscribed on a single click. The button's accessible name is “Unsubscribe Ana from ci-pipeline”.

A subscription is reversible and harmless, so there is no confirmation; Unsubscribe confirms because it silently stops events. If nothing is open to Ana, the menu says so in one line.

UC6Revoke a user

Revoke Ana?

Their 3 devices are revoked and their 3 producers disabled, at once and for good, so the people subscribed to those producers stop receiving them. Their events stay.

warning
This cannot be undone. Ana's name stays taken: names are not case-sensitive and a revoked user keeps theirs, so Ana cannot be invited again under it.
CancelRevoke Ana

The counts come from the pane. If it fails, the banner sits above the text and the dialog stays, as in Devices G6b. An admin user is made Basic as they are revoked.

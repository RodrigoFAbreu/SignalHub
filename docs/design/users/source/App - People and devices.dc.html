3People, inviting someone, and Devices by role

People is an admin's tab. An admin invites people, sets them to Basic or Mod, and manages any device that isn't an admin's. Making someone an admin stays on the admin page on the computer running SignalHub, so the app shows admins but can't change them. 3b lists people in sections by role, each explaining the role. The list comes from an admin-only call, GET /api/v1/client/users, which gives each person only a role, an active device count and whether they have paired a device yet. A person's producers come from a separate call on their page, GET /api/v1/client/users/{id}/producers (id, name, visibility, disabled). The API gives no joined date, so none is shown. Device rows show only what the server records: the name, when it was last active (or revoked, or that it was not used yet), and whether it is this device, an admin device or a browser.

3cDevices for an admin and a Mod: rows, menus, dialogs

The Devices screen follows the role. An admin sees everyone's devices grouped by person, with revoked ones, and can rename, revoke and delete any device that isn't an admin's. A Mod has only their own. A browser is a device and is listed as one, with a globe icon and a Browser tag. Device rows show the name, a tag where one applies (This device in the summary, Admin device, Browser, Revoked) and when it was last active, when it was revoked, or that it is not used yet.
